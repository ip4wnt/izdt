# IZDT

Редактор электронных книг и статичная читалка по [макетам IZDT](https://www.figma.com/design/9jjjVWPHGqUzt9wQxuLIVD/izdt). Интерфейс на Vanilla JavaScript, редактор на ProseMirror, сервер на Node.js, хранение в обычных файлах без базы данных.

## Один репозиторий

Ветка `main` в [ip4wnt/izdt](https://github.com/ip4wnt/izdt) хранит код и данные книги. Работа идёт прямо из локального клона; отдельная ZIP-версия больше не поддерживается.

```sh
git clone https://github.com/ip4wnt/izdt.git
cd izdt
npm run local
```

Нужен Node.js 22.12+. На Windows можно дважды нажать `START-IZDT.cmd`; лаунчер установит зависимости при первом запуске, соберёт редактор и откроет браузер. Git необходим для clone/pull/commit/push, но не для самого сервера.

Подробная [инструкция для Windows](WINDOWS.md) содержит безопасный перенос ваших правок из старого ZIP, настройку шрифтов и повседневную синхронизацию данных.

## Возможности

- Чтение статичного HTML: основной текст доступен даже без JavaScript.
- `Ctrl+E`: редактор (включить и выключить); `Ctrl+S`: сохранение; `Esc`: сохранить и выйти.
- Компактная панель в одну строку, закреплённая у нижней границы окна: стиль, гарнитура, размер, начертание, выравнивание, интерлиньяж (↕) и красная строка (¶) без текстовых подписей; подсказки в `title`. Панель следует за курсором и выделением, показывает смешанные значения. Панель картинки появляется только при выбранном изображении и на это время заменяет текстовые элементы.
- Настройка именованных стилей (кнопка с ползунками рядом со стилем): шрифт, размер, интерлиньяж, красная строка и выравнивание для всех абзацев стиля, например «Обычный текст» по ширине. Отличия от базовых значений хранятся в `styles.json` и попадают в `<style id="book-styles">` читалки; ручное форматирование абзаца и подписи остаются сильнее. Кнопка «Сбросить» возвращает исходные значения стиля.
- Переносы: основной и малый текст переносится браузером по словарю русского языка (`hyphens:auto`, слово от 6 букв, минимум 3 буквы по краям, не более двух переносов подряд, последняя строка без переноса). Заголовки, подписи, параграфы оглавления и текст на картинках не переносятся.
- Пустые абзацы, поставленные для отступа между блоками, сохраняют высоту строки и в читалке.
- На панели слева над кнопкой редактора — индикатор положения в книге (процент прочитанного); он считается по самой книге, поэтому одинаков в читалке и в редакторе.
- Геометрия читалки и редактора совпадает блок в блок: одинаковые правила `white-space`, переноса строк и лигатур, абзац с картинкой в отдельной строке не схлопывает её поля, служебные узлы ProseMirror после такой картинки не добавляют строку. Картинки несут атрибуты `width`/`height` (сервер берёт размеры из файлов, редактор — из загруженной картинки), поэтому при пересоздании `<img>` браузер знает их пропорции и текст не прыгает даже при медленной загрузке. Вход в редактор и выход из него не сдвигают текст.
- Именованные стили H1/H2/H3, обычный/малый текст, параграф оглавления. Стили применяются к выделенным абзацам, ручной размер и гарнитура к текстовому выделению или последующему вводу.
- Изображения из файла, буфера и перетаскиваемого файла. Обтекание слева/справа, отдельная строка или в тексте; положение, ширина, описание, маркер изменения размера, удаление, отмена и повтор.
- Устойчивое выделение и транзакционная история ProseMirror вместо `execCommand`. Корректная отмена применяется и к изменениям стилей/картинок.
- Картинка с текстом (`figure.image-figure`): любую картинку кнопкой «Текст на картинке» можно превратить в блок «картинка + плашка». Плашка перетаскивается за ручку, меняется по ширине маркером или числами в панели (слева, сверху и ширина в процентах от ширины блока, поэтому композиция масштабируется целиком). Блок растёт по содержимому. Кнопка «Снять текст с картинки» возвращает абзацы под картинку; удаление картинки тоже сохраняет её текст. Старый титул `header.opening` при первом сохранении становится таким блоком.
- Типографика: в изменённых абзацах редактор меняет существующие пробелы на неразрывные после предлогов, союзов и коротких слов (1–2 буквы), перед частицами же/ли/бы, между цифрами и перед единицами (г., руб., пуд., %, ₽), после № и §, перед тире (и после тире в начале реплики), в сокращениях т. е./т. д. и инициалах. Новых пробелов он не добавляет, длина текста не меняется. Каждый проверенный абзац получает подпись `data-typo` (хэш текста): пока текст абзаца не меняется, его больше не трогают; смена стиля или выравнивания проверку не запускает. Книга целиком проверяется только по кнопке «Типографика книги». Заметки сравнивают цитаты без различия обычного и неразрывного пробела.
- `C` / `С`: оглавление H2 → H3 → параграф. Названия берутся из текста как есть (система ничего не добавляет от себя, для дополнений есть ручные правки); параграфы нумеруются сквозным образом по всей книге в отдельной колонке («§ 9.», 50 % от цвета текста), названия выстроены по одной линии. Ручные названия, скрытие и индивидуальный сброс сохраняются отдельно.
- В редакторе включена браузерная проверка орфографии (подчёркивание ошибок); в режиме чтения она выключена.
- Выделение текста → «В заметки», жёлтые выделения, группировка по части/главе, переход к фрагменту; `B` / `И`: панель заметок. Кнопка × рядом с заметкой удаляет её вместе с подсветкой; в общем режиме удалённые ID пишутся в `notes-deleted.json`, чтобы старые файлы читателей оставались нетронутыми.
- Анимированная закладка: повторная установка переносит её, нажатие возвращает к месту и снимает.
- Автосохранение, проверка ревизии при конкурирующих изменениях, отказ выхода при ошибке сохранения, локальная история HTML.
- Перед новым блоком (часть, глава) в основном потоке добавлен отступ; внутри титула и плашек он не действует.
- Адаптивность при сужении окна: сначала сжимаются поля с двух сторон до минимума, затем полоса набора (не более чем на 20 %), затем масштаб контента (шрифты, картинки, оглавление и заметки) уменьшается пропорционально вместе с полосой. Текст никогда не уходит за правую границу окна.
- Светлая/тёмная бумага, reduced-motion.

## Код и данные

```text
client/
  schema.js                 # Документ, стили, изображения, картинка с текстом и HTML-сериализация
  editor.js                 # ProseMirror, панель, выделение, история, загрузки
  typography.js             # Правила неразрывных пробелов и подпись абзаца
  typography-plugin.js      # Плагин: проверка изменённых абзацев, проверка всей книги
server/
  index.js                  # HTTP/API и ограничения локального доступа
  store.js                  # Файлы, заметки, ревизии, генерация HTML
  document.js               # Санитизация, стабильные ID, подсветка цитат
  template.js               # Статичная страница и панель
public/js/                  # Читалка, панели, заметки, закладка
shared/model.js             # Общие ID, оглавление и разделы
scripts/build.js            # Сборка редактора esbuild и статичной копии
scripts/start-local.js      # Локальный запуск из папки репозитория
data/books/bees/
  content.html              # Книга и форматирование
  meta.json                 # Название и ревизия
  toc.json                  # Оглавление
  toc-overrides.json         # Ручные правки
  styles.json               # Правки именованных стилей
  img/                      # Иллюстрации
  notes.json                # Общие заметки локальной книги
  notes-deleted.json        # ID удалённых заметок
  bookmark.json             # Общая закладка
  readers/<uuid>/notes.json # Заметки старой версии
  generated/                # Генерируется, вне Git
  history/                  # Локальная страховка, вне Git
```

В режиме лаунчера заметки и закладка общие для всех браузеров этой локальной копии. Старые `readers/<uuid>/notes.json` объединяются по ID без удаления исходников. После переноса этих файлов через Git данные доступны на другом компьютере без переноса localStorage.

Данные сохраняются на диск автоматически, но Git-команды выполняются отдельно и осознанно. Перед pull/commit/push остановите сервер; перед обновлением сохраните незакоммиченные данные. При конфликте разберите его, не используйте принудительную перезапись.

Репозиторий публичный. По явному решению владельца текст, иллюстрации и заметки могут быть опубликованы в нём; не добавляйте чужие приватные материалы без разрешения.

## Шрифты и материалы

Шрифты исключены из Git по лицензионным причинам. Перенесите их из старой локальной версии либо добавьте лицензированные файлы по [инструкции](public/fonts/README.md); `git pull` их не удаляет.

TT Marxiana Trial используется только для тестирования. Для полноценной эксплуатации нужны соответствующие лицензии и разрешение на web embedding. В репозитории находится фрагмент книги из макета, не полное оцифрованное издание; текст требует редакторской сверки.

## Сборка и проверки

```sh
npm ci
npm run build
npm test
npm audit
npx playwright install chromium
npm run test:browser
```

Браузерный тест сам поднимает отдельный сервер на 3189 с временной копией книги и удаляет её после проверки. Он не меняет рабочие данные. Серверные тесты используют порты 3099 и 3191, тоже с временными каталогами.

Снимки и результаты сохраняются в `.qa-output/editor-v2/`. При необходимости укажите `CHROMIUM_PATH` для установленного Chromium. Подробности в [QA.md](QA.md).

`public/js/editor.js` является результатом сборки из `client/`, а не второй редактируемой копией кода. Он, `dist` и `node_modules` исключены из Git и пересобираются лаунчером.

## Режимы сервера

`npm run local` включает `TEST_MODE=1`, `LOCAL_ONLY=1`, `SHARED_DATA=1`, принудительно использует `127.0.0.1`, встроенную книгу и порт `IZDT_PORT` (по умолчанию 3000). Посторонние Origin/Host отклоняются; это локальный редактор без пользовательской авторизации, не публичный сервер.

Для ручного защищённого запуска после сборки задайте `EDITOR_TOKEN` и выполните `npm start`. Без `TEST_MODE=1` и без токена запись книги, оглавления и изображений запрещена. Не храните токен в Git, HTML или URL.

Ручной сервер учитывает `HOST`, `PORT`, `DATA_DIR`. `SHARED_DATA=1` действует только вместе с `LOCAL_ONLY=1`; без общего режима заметки по-прежнему разделены по UUID браузера, а закладка хранится в localStorage. Не используйте публичные туннели для тестового режима.

Файловые операции в одном процессе сериализованы, отдельные файлы заменяются через rename. Несколько файлов не образуют транзакцию файловой системы: до production нужны резервное копирование, журнал восстановления, полноценная авторизация, лимиты запросов и квоты. Запускайте только один сервер на каталог книги.

`dist` является статичным предпросмотром, для редактирования нужен сервер. `PREVIEW_API_BASE` используется только для приватного проксируемого предпросмотра; обычный локальный запуск обслуживает UI и API с одного адреса.
