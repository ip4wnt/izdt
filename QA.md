# Проверка IZDT

Проверено 25 сентября 2026 года после замены редактора на ProseMirror и перехода на запуск из Git. Проверки используют временные каталоги, не меняют рабочий текст книги и не добавляют тестовые заметки в репозиторий.

## Повторяемые команды

Нужны Node.js 22.12+ и установленные зависимости.

```sh
npm ci
npm test
npx playwright install chromium
npm run test:browser
```

Браузерный тест находится в `scripts/qa-editor-v2.js`. Он сам запускает отдельный сервер на порту 3189, останавливает его после проверки и удаляет временные данные; скриншоты и отчёт сохраняет в игнорируемую папку `.qa-output/editor-v2`.

Если Chromium уже установлен вне стандартного пути Playwright, задайте переменную `CHROMIUM_PATH` с полным путём к исполняемому файлу. Порты 3099 и 3191 используются интеграционными тестами и также должны быть свободны.

## Сервер и модель документа

Все 10 тестов `npm test` прошли на Node.js 22.23.3 в Linux.

- Нормализация, HTML-санитизация, стабильные ID, ручное оглавление.
- Заметки внутри форматированного текста, пересекающиеся и неоднозначные якоря.
- Сохранение размеров, гарнитур, выравнивания и обтекания изображений.
- Права редактора, конфликт ревизий с ответом 409, проверка загрузок изображений.
- Изоляция заметок читателей в обычном серверном режиме.
- Запрет посторонних Origin/Host и wildcard CORS в локальном режиме.
- Общие заметки локального режима: объединение старых файлов по ID, доступ из разных профилей, сохранность исходных файлов.
- Общая закладка: запись, чтение, очистка и отказ для неверных данных.

## Браузерные сценарии

Полный проход Chromium (21 проверка) завершился успешно, без необработанных ошибок JavaScript. Сценарий работает на фиксированной копии книги `scripts/fixtures/content.html` (исходный титул `header.opening`), поэтому правки рабочей книги на него не влияют. Модульные тесты: `test/document.test.js` (санитизация блока с плашкой, `data-typo`, заметки с неразрывными пробелами), `test/typography.test.js` (правила, идемпотентность, сохранение длины) и `test/styles.test.js` (проверка и CSS именованных стилей).

Скриншоты редактора, обтекания, заметок и тёмной темы просмотрены визуально. Тест намеренно добавляет длинный заголовок и изображения во временную книгу для проверки крайних состояний; они не попадают в рабочую книгу.

Дополнительная регрессия исправлена после сообщения пользователя: `EditorView.destroy()` удалял класс `book`, ошибочно переданный во владение ProseMirror вместе с атрибутами исходного элемента. До исправления новый тест воспроизводил растяжение колонки и уменьшение текста; теперь редактор управляет только своими временными атрибутами, а снимки до/после выхода сохраняют композицию.

## Локальный запуск и ограничения проверки

Лаунчер использует только встроенные модули Node до установки зависимостей. При первом запуске выполняет `npm ci`, затем собирает редактор и запускает сервер с `LOCAL_ONLY=1` и `SHARED_DATA=1`.

Предыдущая проверка лаунчера включала путь с кириллицей и пробелами, запуск из другой рабочей папки, первую установку зависимостей, повторный запуск, занятый порт, остановку, неверную версию Node и неверный порт. После перехода на Git дополнительно проверена чистая копия исходников без `node_modules`, `dist` и локальных шрифтов: первая установка, сборка ProseMirror, запуск из другой рабочей папки по пути с кириллицей и пробелами, общие данные, лицензии сборки и обновлённая справка.

Настоящая Windows-среда здесь недоступна: двойной щелчок по `START-IZDT.cmd`, ветка `cmd.exe` и автоматическое открытие браузера требуют проверки на компьютере пользователя. Вставка из буфера проверена внутри Chromium; вставку из конкретных Windows-приложений нужно проверить отдельно.

Это настольный редактор книги, не полная копия Word. Мобильная редактура, DOCX, печатная пагинация, совместное редактирование в реальном времени и произвольное наложение объектов не заявлены и не проверялись.
