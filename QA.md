# Проверка первой версии

## Матрица проверок

| Область | Проверка |
|---|---|
| Начальный экран | 1920 и 1440 px, гарнитуры загружены, гравюра, отступы, шум, отсутствие перекрытий |
| Чтение | Прокрутка, выделение, статичный текст без JS |
| Оглавление | Открыть/закрыть кнопкой и C; переход к якорю; сдвиг книги |
| Редактор оглавления | Переименовать, скрыть, восстановить; перезагрузить; добавить заголовок и убедиться в сохранении ручных правок |
| Заметки | Выделить текст мышью, сохранить, перейти из панели, обновить страницу |
| Пустые заметки | Понятное состояние нового читателя |
| Закладка | Установить на прокрутке, обновить, переставить, вернуться; проверить анимацию |
| Редактор | E/У, реальный ввод, авто/ручное сохранение, Esc, повторная загрузка |
| Форматирование | Стили, курсив Ctrl+I, размер/интерлиньяж/отступ, выравнивание, разделители |
| Изображение | Файл и буфер обмена, сохранение в img, обтекание |
| Сбой сети | Нельзя показывать «Сохранено» или выходить из редактора при неудачной записи |
| Конкурентная запись | Старая revision получает 409, данные не перезаписываются |
| Защита | Sanitizer, image signatures, path traversal, ключ редактора, изоляция заметок |
| Дополнительно | Тёмная тема, помощь, клавиатура, отсутствие JS-ошибок |

## Автоматические проверки

`npm test`: нормализация, санитизация, стабильные ID, ручное оглавление, выделения внутри форматирования и с пересечениями, неоднозначные якоря, rem-стили; интеграционный запуск отдельного сервера с временным каталогом данных проверяет API, права, ревизии, заметки, личные HTML и загрузку изображений.

Браузерный проход Playwright в Chromium завершён: 1440×1000 и 1920×1200, загруженные шрифты, открытие оглавления, переходы, переименование/скрытие/сброс, перезагрузка, выделение мышью и создание заметки, возврат по заметке, установка/перестановка/восстановление/потребление закладки, ввод в редакторе, авто/ручное сохранение, выход, перезагрузка, малый стиль, rem-настройки, загрузка файла и обтекание слева, обе темы, справка. Ошибок JavaScript не обнаружено.

Найденная потеря выделения при переключении стиля исправлена: диапазон дополнительно фиксируется на keyup/pointerup и перед взаимодействием с панелью. SVG-разделитель из Figma имел нулевую высоту viewBox; границы экспорта исправлены без изменения контура.

Дополнительный проход `scripts/qa-editor.js` проверил H2/H3, выравнивание, Ctrl+I, B/U/S, undo/redo, оба разделителя, реальную запись PNG в браузерный clipboard и вставку Ctrl+V, отказ сети при сохранении, запрет выхода с несохранённым черновиком, повторную запись после восстановления сети, отказ доступа к localStorage, desktop 1000 px. Проверки прошли.

Мобильный дизайн, полноценное издание и production-аутентификация не входят в текущий объём. Вставку из конкретных приложений ОС ещё следует проверить на компьютере пользователя.
