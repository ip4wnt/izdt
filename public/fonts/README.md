# Шрифты

Для точного соответствия макету положите сюда файлы с разрешением на web embedding:

- `marxiana.ttf`: TT Marxiana Antiqua.
- `marxiana-italic.ttf`: TT Marxiana Antiqua Italic.
- `akzidenz-boldcn.ttf`: Akzidenz-Grotesk Pro Bold Condensed.

Файлы шрифтов исключены из Git. Присланные TT Marxiana Trial применяются исключительно для тестирования типографики в закрытом предпросмотре. В метаданных Trial прямо запрещено использование в личных и коммерческих проектах. Для production необходимы подходящая лицензия и полноценные веб-шрифты. Лицензию Akzidenz также необходимо проверить до публикации.

Без этих файлов применяется системный serif/sans-serif fallback; это не точное соответствие макету.
